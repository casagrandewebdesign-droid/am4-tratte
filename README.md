# AM4 – Configurazione tratte

Calcolatore non ufficiale per Airline Manager 4 (A380-800, A330-900neo e A330-800neo): quanti aerei mettere su una tratta, come configurarli (tutte le classi nel rapporto della domanda) e quanto rendono, con carburante, CO₂ e A-check.

Si apre dal browser e si può installare sul telefono ("Aggiungi a schermata Home").

Le formule di prezzi e consumi sono stime della community (abc8747/am4): i risultati sono indicativi.
