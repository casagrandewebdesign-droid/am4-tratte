# AM4 Configuratore Tratte

Calcolatore non ufficiale per Airline Manager 4: scegli l'aereo e la tratta, e vedi quanti aerei mettere, come configurarli (tutte le classi nel rapporto della domanda) e quanto rendono (ricavi meno A-check; carburante e CO₂ esclusi).

Aerei disponibili: Airbus A380-800, A330-900neo, A330-800neo, Boeing 737 MAX 10, 737-800.

Si apre dal browser e si può installare sul telefono ("Aggiungi a schermata Home").

Le formule di prezzi e A-check sono stime della community (abc8747/am4): i risultati sono indicativi.
